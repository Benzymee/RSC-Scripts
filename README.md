# RSC-Scripts

A personal collection of IdleRSC/OpenRSC automation scripts, helper classes, and experimental utility files.

## Important note

This repository is a mixed-source collection of scripts and files. Many of the entries were created, modified, or heavily assisted using AI tools, so a lot of the code here is best described as "vibe coded" — quick, experimental, and built with AI-assisted generation rather than formal engineering discipline.

Some scripts in this repo are original work, while others are adapted, assembled, or generated from examples, tutorials, community resources, or AI-assisted drafts. Not all files are my own work, and I do not claim authorship of every script in this project.

## Overview

RSC-Scripts contains Java-based scripts intended for use with IdleRSC/OpenRSC automation workflows. The collection includes scripts for:

- fishing and gathering
- thieving and stealth-based tasks
- woodcutting and resource collection
- travel and route-based scripts
- questing and account setup
- example and template scripts for learning and adaptation

This repo is best understood as a personal archive and script dump rather than a polished, single-authored framework.

## Repository purpose

The goal is to keep useful automation scripts, examples, and reference code in one place for experimentation, learning, and personal use. Most files are designed to be placed into the external scripts folder used by IdleRSC, where they can be hot-loaded and reloaded without rebuilding the client.

## How to use

1. Open IdleRSC.
2. Place or edit the Java files in your external scripts directory.
3. Reload the script list within the client.
4. Start the script you want to use.

This repository follows the standard IdleRSC external script workflow: add or edit Java files in the scripts directory, save them, then reload them from inside the client.
